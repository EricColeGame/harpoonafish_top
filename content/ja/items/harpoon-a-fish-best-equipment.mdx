## なぜ銛は今も船べりで最強なのか

フライングギャフは写真映えするが、魚をきれいにランディングするクルーはたいてい銛を手にしている。リーダー際で暴れるクロマグロ、水面直下で光るメカジキなど、終盤の勝負が数秒で決まるとき、リーチとコントロールはいつでも力任せの腕力を上回る。だからこそ経験豊富なオフショアアングラーは、魚を銛で突くためのベスト装備を単品の買い物ではなく、完成されたシステムとして扱う。

この道具自体は古い。沿岸の狩人、先住民の漁師、ナンタケットの捕鯨クルーは皆、取り外し可能な穂先を備えたシャフトを使っていた。現代のスポーツフィッシング用も同じ原理で動く。変わったのはハードウェアだ。折りたたみ式シャフト、交換可能なダーツ、揺れるデッキから正確に投げられるよう設計されたラインシステム。

核となる利点は単純だ。ギャフの一撃は魚が舷縁から手の届く距離にいることを前提とし、その打撃はアングラーに向かって引く動き——体重全体をシャフトに乗せられるやり投げ式の投擲よりはるかに小さな力しか生まない。銛なら、まだ数フィート先にいる魚にも、レール越しに飛びかかるのではなく、流れるような動きでマテが突き込める。

| 要素 | 銛 | フライングギャフ |
|---|---|---|
| 有効距離 | 舷縁から数フィート先まで | 魚が船の近くにいる必要がある |
| 力の源 | 全身を使ったやり投げ | 腕と肩で引く |
| 傷の性状 | 小さくきれいなダーツ穴 | 大きなフックの開口部 |
| 身の損傷 | 低い、特にマグロで | ロイン周辺で高い |
| 収納 | 分解してバッグに収まる | 長い柄、露出したフック |
| クルーの安全 | デッキ上での刺し傷リスクが低い | 混み合うコックピットでフックが振れる |
| IGFA世界記録での使用 | 認められていない | 認められている |

1ドル使う前に重要なルールが一つある。[IGFA世界記録規則](https://www.igfa.org/)によれば、記録申請する魚を弱らせるために銛を使ってはならない。そのため記録狙いの釣り人は今も合法なギャフで止めを刺す。それ以外の人は、より速く、切身へのダメージを少なく戦いを終わらせる道具を選べばよい。

## 「魚を銛で突くベスト装備」に実際に含まれるもの

「魚を銛で突くベスト装備」で検索するアングラーは通常、一つの答え——一本のシャフトや一つのブランド——を期待する。実際には6〜7点の部品からなるシステムであり、最も弱い部品が成功率を決める。シャフトは最も地味な部品だ。突き込んだ後は、ダーツ、ライン、フロートがほとんどの仕事を担う。

| 部品 | 一般的なオフショア仕様 | 重要な理由 |
|---|---|---|
| シャフト | 6フィートのコックピット用、または10フィートのウェイト入り折りたたみ式 | 長さが射程と投擲スタイルを決める |
| ダーツ（リリー） | 交換可能なヘッド、先端の上3分の1だけを研ぐ | 刺さった後に引き抜き方向へ切れ広がらない |
| ダーツライン | 約4フィートの5/16インチ三つ撚り、またはワイヤー | 突撃の衝撃を吸収。ワイヤーはざらつく皮膚に強い |
| メインライン | 約200フィートの3/8インチ三つ撚り、スプライス済みループ付き | ダーツライン用とボール用に各1つのループ |
| ポリボール | メインラインにA-1タイプのポリボール | 抵抗を加え、魚を疲れさせ、位置を示す |
| テープ | 電気テープ | 投擲中にダーツをシャンクに固定する |
| 収納 | バスケット、ボックス、分解バッグ | 200フィートのラインを絡ませず、すぐ使える状態に保つ |

見落としやすい点が二つある。第一に、ほとんどのダーツは研がれていない状態で出荷されるので、出航前に刃を付ける時間を見込んでおくこと——ただし先端の上3分の1だけ。ヘッド全体を研ぐと、魚に深く刺さった後にダーツ自身が切り抜けて外れてしまう。第二に、柄の近くにオプションのクリップを付ければ、外した後にシャフトを素早く回収でき、船底へ滑り込むのを見送らずに済む。

## 負荷がかかっても破綻しない仕掛けの手順

仕掛けの好みはクルーによって異なるが、作業の順序は変わらない。前夜にこの手順を済ませ、夜明けにテープとダーツの装着状態を再確認する。

| 手順 | 作業 | 詳細 |
|---|---|---|
| 1 | ダーツを研ぐ | 先端の上3分の1だけ、両面 |
| 2 | ダーツをダーツラインに結ぶ | ダーツ側はもやい結び |
| 3 | ダーツラインをメインラインのループに結ぶ | スプライスループ側はもやい結び |
| 4 | ダーツをシャフトのシャンクに装着する | しっかりと、まっすぐ、奥まで装着 |
| 5 | ダーツラインをシャフトにテープ留めする | 電気テープを2周、きつめに |
| 6 | メインラインをバスケットかボックスに捌いて入れる | ループやねじれを作らず、ボールを付けたまま |
| 7 | 回収テストをする | 仕掛け全体を持ち上げ、収まるのを確認する |

テープを巻く工程は省略されやすく、そして魚を逃す原因になる。これがないと、投擲の途中でダーツがシャンクから外れ、突き込み全体が水しぶきで終わる。ダーツラインの両端をともやい結びにしておくことも、魚が掛かった後に効いてくる——強い負荷がかかった後でもきれいにほどける。

オフショアクルーのコミュニティ報告によれば、専用のライン用バスケットを使うか、緩い巻き線を入れたバケツを使うかが、きれいな投擲と最悪のタイミングでのバードネスト（絡み）を分ける。ラインは広いループで捌き、ボールを一番上に置く。

## シャフト長を狙う場面に合わせる

万能な長さはない。短いシャフトは混み合うコックピットで扱いが速い。長いウェイト入りシャフトは近づいてこない魚に届く。

| 長さ | 最適な用途 | 投擲スタイル | 収納 |
|---|---|---|---|
| 6フィート | 船べりでの突き込み、コックピット作業 | 手繰り寄せながらの突き出し | 直立ホルダーに収まる |
| 8フィート | 一般的なオフショア、サイズ混合 | 短いやり投げ | 2分割 |
| 10フィート・ウェイト入り | 船首方向の魚、またはギャフの届かない魚 | 本格的なやり投げ | 約4フィートの分割式 |

スポーツボートではスペースが現実的な制約になる。だから折りたたみ式が人気になった。2003年に市場に出たPOON Harpoonは、コミュニティ報告でこの種の最初の折りたたみ式システムとして広く言及されており、10フィートのシャフトをバッグ収納用に約4フィートまで分割できる。市販の分割モデルを買うにせよ自作するにせよ、収納の問題はシャフトそのものと同じくらい重視する価値がある——ほかに置き場所がないからロッカーに住み着く銛は、バイトが来たときに仕掛けられない銛なのだ。

## 投擲テクニック：魚の下を狙う

これは銛釣りで最も役立つスキルであり、純粋な物理現象だ。水は光を屈折させるため、見えている魚は魚の実際の位置ではない——真の位置より少し高く、遠くに見える。シルエットを狙うと、毎回ダーツが背中を越えて飛んでいく。見えている位置より数インチ下を狙えば、ヒット率はすぐに上がる。

狙い以外では、投擲は突きではなくやり投げの動作だ。安定したデッキに足を固定し、シャフトを水面と平行に保ち、肩と腰で押し込む。投げ過ぎないこと。フォロースルーを伴うコントロールされた投擲は、無茶な力投に勝る。

| ミス | 起こること | 対策 |
|---|---|---|
| 見えている魚を狙う | ダーツが背中を高く越える | シルエットより少し下を狙う |
| ダーツをシャフトにテープ留めしていない | 投擲中にダーツが外れる | 電気テープを2周 |
| バケツにラインを緩く巻いてある | 突き込み時に絡む | バスケットかボックスに捌いて入れる |
| ダーツ全体を研ぐ | 負荷でヘッドが切り抜ける | 上3分の1だけ研ぐ |
| バランスを崩して投げる | 弱い突き込み、転倒リスク | 安定した構え、完全なフォロースルー |
| 元気な魚の頭を狙って追う | 外して時間を失う | 落ち着いた横向きの的を待つ |

## 手入れ、収納、出航前チェック

塩と日光は魚よりも速く銛装備を破壊する。毎回の釣行後にダーツとシャフトを真水ですすぎ、ラインはバスケットに戻す前に乾かし、ダーツラインがヘッドと接する部分の摩耗を点検する。擦り切れて薄くなったものは修理せず交換する。

| チェック項目 | 基準 | 見逃した場合の結果 |
|---|---|---|
| ダーツの刃 | 上3分の1が鋭く、バリなし | 貫通不足、ダーツが抜ける |
| テープ巻き | 新しいテープをきつく2周 | 投擲中にダーツが落ちる |
| メインライン | 擦れなし、巻き癖なし | 突き込み時に切れる |
| ポリボール | 膨らみ、結び目が固い | 魚とラインを失う |
| シャフトの継ぎ目 | 清潔、ロック済み、ぐらつきなし | 力の伝達が弱い |
| 収納バッグ | 乾燥、ラインを捌いてある | カビと絡み |

マグロ、メカジキ、アオザメのシーズン中は、仕掛けを組み立てたまま準備しておく。トロフィーの瞬間は予告なく訪れる。組み立てに5分かかる銛は、バッグの中に留まり続ける銛だ。オフショアクルーの古い言葉どおり——人生は大物を逃すには短すぎる。

## FAQ

**初めてのオフショア釣行なら、魚を銛で突くベスト装備の構成は？**
10フィートの折りたたみ式シャフト、研いだ予備ダーツ1本、約4フィートの5/16インチ・ダーツライン、スプライス済みループ付きの約200フィートの3/8インチ三つ撚りメインライン、ポリボール、電気テープ、ライン用バスケットから始めよう。これで仕掛け、投擲、回収を過剰な出費なしにカバーできる。

**銛を持っていてもフライングギャフは必要？**
はい。銛は魚を確保して疲れさせますが、船に上げるには合法なギャフが依然として必要です。さらにIGFA記録を狙う場合、ギャフだけが認められた止め道具です。

**銛のダーツはどれくらい研ぐべき？**
触れただけで皮を切る程度に鋭く。ただし研ぐのは先端の上3分の1だけです。ヘッド全体を研ぐとよく貫通するものの、その後自分で出口を切り開いてしまい、まさにそれが魚が外れる原因になります。

**銛で突いてからリリースできますか？**
銛突きは致死性またはそれに近いテクニックで、持ち帰る予定の魚に使うものです。リリースが目的なら、リーダーまでファイトしてリリースギャフを使うか、リーダーを切ってください。

**長い銛ほど常に良い？**
いいえ。10フィートのウェイト入りシャフトはより遠くに届きますが、6フィートのコックピット用銛は混み合うデッキでより速く、安全です。長さはドックで格好よく見えるかではなく、実際にどこで突くかに合わせてください。
