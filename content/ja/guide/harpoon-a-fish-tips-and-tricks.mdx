大型クロマグロがトランサムから10フィートのところまで浮上し、ギャフ担当が外海に身を乗り出す。そして、起きうるトラブルが一斉に起き始める。ボートと魚の間のその距離こそ、銛が真価を発揮する場所です。確かな**魚を銛で突くコツとテクニック**があれば、混沌として危険な終盤戦が一度のコントロールされた投擲に変わり、きれいにランディングできるか、逃げられた魚の話になるかの差を生みます。

この道具自体は古くからあります。沿岸で狩りをしていた初期の人々からナンタケットの捕鯨船員まで、漁師は何千年もの間、槍や銛で魚を捕ってきました。変わったのは装備です。現代のダーツ、分解式シャフト、専用設計のラインによって、銛は船際でトロフィー級の魚を確実に捕らえる最も効率的な方法の一つになりました。以下の**魚を銛で突くコツとテクニック**では、仕掛け、研ぎ、投擲のメカニクス、そして魚を逃すミスについて解説します。

## フライングギャフを使う代わりに銛で魚を突く理由

銛を選ぶ理由は、射程とパワーにあります。フライングギャフでは、クルーが魚を腕の届く範囲まで引き寄せ、魚の上や向こう側に手を伸ばして、ボート方向へ引き戻さなければなりません。その動きは短く、ぎこちなく、やり投げのように全身をストライクの後ろに使える投擲に比べて弱いものです。銛なら、まだギャフの届く範囲の外にいる魚にも、流れるような思い切った動作で届きます。

身質の面でも利点があります。大きなフライングギャフはクーラー行きの魚に大きな穴を開けますが、ダーツなら傷ははるかに小さく、ロインをより多く無傷で残せます。持ち帰るつもりの魚では、その差はまな板の上で明らかになります。

仕掛ける前に重要な注意点が一つあります。世界記録を狙う場合、銛は禁止されています。記録申請に自分の装備が合法だと決めつける前に、[IGFAの公式ルールと記録認定基準](https://www.igfa.org/)を読んでください。

| 要素 | 銛 | フライングギャフ |
|---|---|---|
| 有効射程 | 腕の届く範囲をはるかに超える | 魚が船際にいる必要がある |
| 動力源 | 全身を使ったやり投げ | 釣り人方向への短い引き |
| 傷の大きさ | ダーツによる小さな刺し傷 | 身に大きな裂け目 |
| デッキ上の安全性 | 簡単に収納でき、露出したフックが振り回されない | クルーやタワーの近くでは扱いにくい |
| 外した時の回収 | ラインとポリボールですばやく再セットできる | ギャフを手でセットし直す必要がある |
| 最適な用途 | 手の届かない所にいる大物 | すでに船際にいて大人しい魚 |

## 銛の仕掛け：ライン、結び方、ダーツのセットアップ

仕掛けは、ほとんどの**魚を銛で突くコツとテクニック**の出発点です。なぜなら、完璧な投擲でもラインが悪ければ、海に寄付するだけだからです。目標は、自由に飛び、負荷に耐え、数秒で再セットできるシステムです。

### メインラインとダーツライン

実績のあるセッティングは、約200フィートの3/8インチ三つ撚りナイロンメインラインを使い、両端にスプライスループを作ります。片方のループはダーツライン用、もう片方はポリボール用です。ダーツライン自体は、5/16インチ三つ撚りラインの約4フィートの短い部分です。もやい結びで2か所を接続します。ダーツラインとメインラインのループ、そしてダーツラインとダーツです。もやい結びはよく保持し、激しいファイトの後でも簡単にほどけます。急いで再仕掛けするときに重要な点です。

ポリボールは飾りではありません。抵抗と視認性を加え、走った魚を追跡・回収しやすくし、外した後にラインを見つけやすくします。

### ダーツの固定とラインのテーピング

ダーツをシャンクに載せたら、絶縁テープでダーツラインをシャフトにテープ留めします。これにより、投擲中にダーツが滑り落ちるのを防ぎます。恥ずかしく、高くつく外しを防ぐ小さな一手です。銛によっては、ハンドルのもう少し下側にクリップが付いています。そのクリップがあれば、投擲がそれた時にシャフトを素早く船内に引き戻せます。

### ダーツにはワイヤーかブレードか

ダーツは、魚の粗い皮膚による擦れに強いワイヤー、または三つ撚りブレードラインに仕掛けることができます。サメやその他の擦れの強い魚種にはワイヤーの方が安全です。ブレードは軽く、扱いやすいです。仕上げたメインラインを巻き、ポリボールと一緒にバスケットか箱に収納して、最悪のタイミングで絡まるのではなく、きれいに繰り出されるようにします。

| 構成要素 | 一般的な仕様 | 役割 |
|---|---|---|
| メインライン | 3/8インチ三つ撚り、両端スプライスループ付きの200フィート | 走りを受け止め、回収を可能にする |
| ダーツライン | 5/16インチ三つ撚りの約4フィート | ダーツとメインラインをつなぐ |
| 結び方 | ダーツラインの両接続部にもやい結び | 強く、ほどきやすい |
| テープ | シャフトへの絶縁テープ | 投擲時にダーツを所定位置に保つ |
| 浮力体 | テールループのポリボール | 抵抗、視認性、回収 |
| 収納 | バスケットまたは箱 | 絡まずに展開 |
| ダーツ素材 | ワイヤーまたは三つ撚りブレード | 耐摩耗性 |

## 研ぎと投擲：ショットを決める2つのスキル

ほとんどのダーツは切れない状態で届くため、研ぎは任意ではなく必須の工程です。刺さったまま保持されるダーツと、魚の動きでのこぎりのように切れて抜けてしまうダーツを分けるルールがあります。先端の上3分の1だけを研ぐことです。刃全体を研いだダーツは、魚がファイトするにつれて広がる切り込みを作り、ダーツが抜けてしまいます。先端は鋭く、奥は鈍い形状なら、きれいに貫通し、その場にとどまります。

### 屈折を克服する：見えている魚より下を狙う

魚を船際で突くのではなく投げる場合は、屈折を考慮しなければなりません。水は光を曲げるため、見えている魚は実際の魚の位置とは違います。水の入ったコップに鉛筆を入れたときの古典的な効果です。的そのものではなく、少し下を狙ってください。このひとつの補正は、身につけるべき最も価値の高い**魚を銛で突くコツとテクニック**の一つです。ニアミスを確実なヒットに変えてくれるからです。

### 投げ方そのもの

- 後方に障害物のない状態でバランスよく立ちます。シャフトの軌道に入る人がいてはいけません。
- コイルをフリーに保ち、クリートに引っかからずラインが繰り出されるようにします。
- 思い切って投げます。迷いを伴う半速の投擲は、必ず届きません。
- インパクト後はフォロースルーし、魚ではなくラインを見ます。
- ヒットを声に出して伝え、船長とアングラーが魚が刺さったことを把握してバックダウンできるようにします。

| スキル | やること | 重要な理由 |
|---|---|---|
| 研ぎ | 先端の上3分の1だけを刃付けする | 貫通するが、切れて抜けにくい |
| 狙う位置 | 見えている魚より少し下 | 光の屈折を補正する |
| グリップと構え | バランスよく、軌道を確保し、コイルをフリーに | 全身の力を使え、絡まない |
| フォロースルー | インパクト後にラインを見る | 刺さったことを確認し、クルーに合図する |
| コミュニケーション | ヒットを告げる | バックダウンとライン整理を連携させる |

## 銛の長さ、収納、ボートセッティングの選び方

銛は万能サイズではありません。約6フィートの短いコックピットモデルは、すぐ船際の魚を突くために作られており、コンパクトなシャフトは扱いやすいです。10フィートのウェイトモデルはリーチを伸ばし、より遠くの魚に投げられるだけの質量を持ちます。長く重いほど射程は伸びますが、より力が必要で、デッキスペースも多く使います。

スポーツボートではスペースが本当の制約です。約4フィートのセクションに分解でき、バッグに収納できる折りたたみ式デザインならその問題を解決し、コックピットのスペースを犠牲にせず銛を仕掛けたまま準備できます。ターゲットにアオザメ、メカジキ、巨大クロマグロが含まれるなら、仕掛け済みの銛をスタンバイさせておくことが、トランサムでの短いチャンスをランディングに変えます。

| 銛の長さ | 得意な場面 | 投げ方 |
|---|---|---|
| 約6フィートのコックピットモデル | 船際の魚を突く | 短くコントロールされた突き |
| 約10フィートのウェイトモデル | トランサムから離れた位置にいる魚 | 本格的なやり投げ |
| 折りたたみ式（約4フィートに分解） | 収納スペースが限られたボート | セッティング次第でどちらも |
| 予備のダーツとラインセット | 外した後や魚を捕った後の再仕掛け | 交換して素早く再セット |

## よくある質問

**魚を銛で突くことに法的制限はありますか？**
はい、場合によってはあります。IGFAの世界記録申請では銛は禁止されており、魚種ごとのルールは地域によって異なります。釣りをする前に、地元の規制と最新のIGFAルールブックを確認してください。

**銛で実際にどれくらいの距離まで届きますか？**
10フィートのウェイト付き銛をやり投げ式で投げると、ギャフの届く範囲をはるかに超えてリーチを伸ばせます。それが狙いです。トロフィー級の魚に試す前に、ブイや浮かぶ的で練習してください。

**魚を銛で突くコツとテクニックの中で最も重要なものは何ですか？**
魚より下を狙うことです。屈折により見えている的は実際より高く見えるため、これを補正することが他のどの単一の調整よりも多くのミスを減らします。

**銛を持っていてもフライングギャフは必要ですか？**
多くのクルーは両方を用意していますが、仕掛け済みの銛は船際での大物の状況の大半に対応でき、身へのダメージが少なく、デッキ上のリスクも低くなります。
